# CTEC GB 2024 Scenes
Example of use: https://www.youtube.com/watch?v=OGleN60BuaM

## Before importing to OBS:
Place your actual path to this repo in the json file for all image files like so:
```bash
sed -i 's/TODO_REPLACE_PATH/\/home\/myuser\/programming_stuff\/obs-scenes/' oldctecgb.json
```

After importing to OBS all files should be found.
Make one of the screenshots in an interceptor scene visible and check if it looks fine on the 2- or 4-player scene.
